# FinAlly Project – AI Finance Platform

## Project Documentation

All project documentation is located in the `planning/` directory.

### Primary Documents

- `planning/PLAN.md` – Master project roadmap, architecture, product vision, milestones, and development status.
- `planning/MARKET_DATA_SUMMARY.md` – Summary of the completed market data component.
- `planning/archive/` – Historical design documents, research, implementation notes, and previous versions.

## Context Loading Rules

To minimize context usage:

- **DO NOT automatically read or import `planning/PLAN.md`.**
- Only open documentation when it is directly relevant to the current task.
- Start with the smallest document that answers the question.
- Prefer `MARKET_DATA_SUMMARY.md` for anything related to market data.
- Consult files in `planning/archive/` only if additional historical context is required.
- Read only the necessary sections instead of entire documents whenever possible.
